# FrameMate — 개인용 AI 구도 카메라 (웹앱/PWA)

안드로이드 크롬에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다. 서버나 API 키는 필요 없고, 모든 처리가 폰 안에서 이루어집니다.

## 기능
| 기능 | 내용 |
|---|---|
| 3분할 격자 | 화면을 가로세로 3등분하는 선 |
| 수평계 | 폰 기울기 센서로 수평선 표시. 1° 이내로 맞추면 초록색. 세로 화면에서만 동작 |
| AI 구도 가이드 | 사람·사물 감지 (MediaPipe EfficientDet-Lite0, 폰에서 직접 실행) → 사람은 머리를 위쪽 3분할선에, 사물은 3분할 교차점에 오도록 화살표와 문구로 안내. 맞으면 초록색 표시와 진동 |
| 줌 추천 | 피사체가 너무 작거나 크면 "🔍 2x 로 확대" 버튼 표시 |
| 줌 | 1x/2x/3x 버튼, 두 손가락 핀치. 하드웨어 줌을 지원하는 기기는 렌즈 줌, 아니면 디지털 줌(최대 4x) |
| 필터 10종 | 원본, 트래블 필름, 포트레이트, 비비드, 골든아워, 쿨 시티, 페이드, 빈티지, 모노, 누아르. 미리보기와 저장 결과가 같도록 맞춤 |
| 기타 | 화면비(3:4, 1:1, 9:16, 전체), 타이머(3초, 10초), 전면/후면 전환, 촬영 즉시 저장, 공유 |

사진은 **다운로드 폴더**에 `FrameMate_날짜_시간.jpg`로 저장되고, 갤러리 앱에서도 보입니다.

## 폰에 설치하는 방법
카메라는 **https 주소에서만** 동작합니다. GitHub Pages를 쓰는 방법이 가장 간단합니다.

1. 이 브랜치를 `main`에 합칩니다. 또는 Pages 설정에서 배포할 브랜치를 이 브랜치로 지정합니다.
2. GitHub 저장소에서 **Settings → Pages → Build and deployment**: Source를 `Deploy from a branch`로, 브랜치와 폴더 `/ (root)`를 선택한 뒤 저장합니다.
3. 1~2분 후 폰 크롬에서 `https://<계정>.github.io/<저장소>/cam/` 을 엽니다.
4. 카메라 권한을 허용합니다.
5. 크롬 메뉴(⋮) → **홈 화면에 추가**(또는 "앱 설치")를 누르면 아이콘이 생기고 전체 화면으로 실행됩니다.

## 코드를 고친 뒤
`sw.js`의 `VERSION` 값을 올려야 폰에 캐시된 예전 버전이 새 버전으로 바뀝니다.

## 한계 (웹앱이라서 생기는 것)
- 볼륨 버튼으로 촬영할 수 없습니다.
- 초광각(0.5x) 렌즈 전환은 기기마다 다릅니다.
- "고화질 촬영"은 센서 사진과 미리보기의 화면비가 같을 때만 쓰입니다. 다르면 구도가 어긋나므로 미리보기 해상도로 저장됩니다. 실제 해상도는 설정(⋯) 화면에 표시됩니다.
- 수평계는 세로로 들고 찍을 때만 표시됩니다.

## 구성
- `app.js`: 카메라, 줌, 촬영·저장, 화면 그리기
- `guide.js`: 구도 판단 규칙 (주 피사체 선택, 목표 위치, 안내 문구, 줌 추천)
- `filters.js`: 필터 정의 (미리보기와 저장에 같은 값 사용)
- `vendor/mediapipe/`: MediaPipe Tasks Vision 0.10.21 (Apache-2.0)
- `models/efficientdet_lite0.tflite`: 사물 감지 모델 (COCO 80종)
